# lead-bot

Telegram-бот заявок на услугу **без нейросети**. Работает как вебхук на Vercel. Есть простая лендинг-страница со ссылкой на бота.

## Как работает

1. Пользователь пишет `/start` или открывает чат — внизу постоянная кнопка **«Оставить заявку»**.
2. Сразу после кнопки — выбор **услуги**: Замер / Ремонт / Консультация / Другое.
3. Дальше по шагам: **имя** → **телефон** → **комментарий**.
4. Готовую заявку бот шлёт текстом в `ADMIN_CHAT_ID` (в том числе поле **Услуга**).
5. Состояние диалога — **в памяти** процесса.

Отмена: `/cancel`.

## Сайт

Лендинг: https://lead-bot-wine.vercel.app

Кнопка ведёт на https://t.me/servrequests_bot

## Вебхук

`https://lead-bot-wine.vercel.app/api/bot`

- **POST** — апдейты от Telegram.
- **GET** — регистрирует вебхук через `setWebhook` (токен из env).

```bash
curl https://lead-bot-wine.vercel.app/api/bot
```

## Переменные окружения (Vercel)

| Имя | Назначение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен бота от @BotFather |
| `ADMIN_CHAT_ID` | chat id, куда слать заявки |

Ключи **не** кладутся в Git.

## Файлы

- `index.html` — лендинг
- `api/bot.js` — вебхук
- `vercel.json` — настройки деплоя
