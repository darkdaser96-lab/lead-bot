# lead-bot

Telegram-бот заявок на услугу **без нейросети**. Работает как вебхук на Vercel.

## Как работает

1. Пользователь пишет боту `/start`.
2. Бот отвечает коротким приветствием и показывает **постоянную кнопку «Оставить заявку» внизу чата** (не нужно каждый раз писать `/start`).
3. По нажатию кнопки по шагам спрашивает: **имя** → **телефон** → **комментарий**.
4. Готовую заявку отправляет текстом в чат `ADMIN_CHAT_ID`.
5. Состояние диалога хранится **в памяти** процесса (на Hobby Vercel после «засыпания» функции шаги могут сброситься — тогда снова `/start`).

Отмена: `/cancel`.

## Вебхук

Публичный URL вебхука:

`https://lead-bot-wine.vercel.app/api/bot`

- **POST** — апдейты от Telegram.
- **GET** — регистрирует этот URL через `setWebhook` (токен берётся из env на сервере).

После деплоя один раз открой GET-адрес в браузере или:

```bash
curl https://lead-bot-wine.vercel.app/api/bot
```

## Переменные окружения (Vercel)

| Имя | Назначение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен бота от @BotFather |
| `ADMIN_CHAT_ID` | chat id, куда слать заявки |

Ключи **не** кладутся в Git и **не** попадают в HTML.

## Файлы

- `api/bot.js` — serverless-функция вебхука
- `vercel.json` — настройки деплоя

## Деплой

Репозиторий уже привязан к проекту Vercel `lead-bot`. После пуша в `main` (или ручного deploy) дождись Ready и вызови GET вебхука, чтобы Telegram узнал новый URL.
